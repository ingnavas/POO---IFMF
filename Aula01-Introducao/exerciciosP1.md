JAVA
☕ Java é considerada uma linguagem compilada porque o código fonte (.java) é transformado antes de executar. O compilador javac converte o código em bytecode (.class). Esse bytecode não roda direto no sistema operacional. Ele é executado pela Java Virtual Machine (JVM). Assim, o mesmo programa pode rodar em diferentes sistemas sem alteração.
